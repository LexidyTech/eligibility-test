# France Visitor Visa — Eligibility Test

Test de elegibilidad interactivo para el visado de larga estancia (Visitor Visa) de Francia, de Lexidy.

El usuario deja sus datos, responde unas preguntas rápidas y recibe al instante si es
elegible. Si lo es, puede ver los planes (Bronze / Silver / Gold), reservar una llamada
gratuita y completar el pago. Si no lo es, deja sus datos para que el equipo le encuentre
la vía adecuada.

## Ver la página
Publicada con GitHub Pages: https://TU-USUARIO.github.io/visa-france/

## Detalles
- Archivo único y autónomo (`index.html`): incluye estilos, JavaScript, tipografía,
  iconos e imagen. Funciona sin dependencias externas.
- No requiere instalación ni servidor: basta con abrir el HTML o alojarlo en cualquier
  hosting estático.
